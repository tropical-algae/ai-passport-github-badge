# Upstream synchronization policy

Automatic upstream synchronization is removed from this standalone application.
There is no daily schedule or upstream merge workflow. Review upstream changes
manually and integrate only the changes appropriate for the badge application.
The sole workflow is the [manual build and release](CI-build-and-release.md).
